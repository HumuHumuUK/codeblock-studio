# Code Studio font variants

The Code Studio ST derivative normalises ASCII advances to 1024 units (eight pixels); the upstream asterisk had a 896-unit advance. Glyph outlines are unchanged.

Generated 6 November 2026 by Ada (OpenAI Codex) under Leonard Powers’ direction. These modified fonts retain the upstream Creative Commons Attribution Share Alike 3.0 licence. The original font and its licence/readme are kept unchanged alongside them. Source, author and original homepage are identified in README.md in the parent directory and in the original notices.

Regenerate with scripts/prepare-retro-fonts.py (FontTools required only for regeneration). The derivatives have new internal names and filenames.
